使用贴近实际的场景、完整应用和共享待办事项，在软件开发生命周期中探索 GitHub Copilot。通过迭代规划更改、编写代码、测试行为、审查拉取请求并使用智能体管理工作。

## 场景

你是 Tailspin Toys 的新开发者。这是一家为桌游众筹的平台，主题围绕开发者文化。团队已将待办事项整理为 GitHub 议题，供你选取。其中既有筛选和分页等功能，也有无障碍和编码规范等质量改进工作。

## 选择工作环境

无论你在哪里工作，都可以使用 GitHub Copilot。选择最适合你的开发环境。每个工作坊都有独立的设置流程，并使用同一个 Tailspin Toys 场景。

### [GitHub Copilot CLI][cli]

在终端中使用智能体式助手。了解 Plan 和 Autopilot 模式、说明、技能、自定义智能体、Playwright MCP、Agent Merge 和实用斜杠命令。

### [GitHub Copilot app][app]

在桌面应用中运行并行智能体会话、切换会话模式、协作使用画布，以及管理 GitHub 议题和拉取请求。

### [GitHub Copilot 云端智能体][cloud]

将 GitHub 议题分配给异步智能体，引导其工作、监视进度并审查它创建的拉取请求。

### [Visual Studio Code][vscode]

在 Visual Studio Code 和 GitHub Codespaces 中使用 GitHub Copilot。无需离开编辑器，即可使用 Copilot Chat 智能体模式、MCP 服务器和自定义智能体。
